# Client Testimonial Photos

## GDPR Privacy Guidelines

### Mandatory Consent
Before publishing any photo:
- ✅ Obtain written and signed consent from the client
- ✅ Specify the use: website, promotional materials, social media
- ✅ Allow the possibility to revoke consent at any time
- ✅ Archive the signed document (digital or paper)

### Privacy Consent Template
```
IMAGE PROCESSING CONSENT

I, the undersigned __________________, born on _________, authorize Arianna Ciervo / Pura Essenza Vegetale to:

☐ Use my photographic image on the website
☐ Use my written testimonial
☐ Publish on social channels (Instagram, Facebook)

The photo will be used for:
- Testimonials section of the website
- Promotional materials

Date: ___________
Signature: ___________
```

### Safe Alternatives
If you do not have photos with consent:
- Use **initials only** (e.g., "Giulia M.")
- The Testimonials component creates **automatic placeholders** with the first letter
- Use **illustrated avatars** or **generic icons**
- **Generic stock photos** (not personal)

### Photos of Minors
⚠️ **ATTENTION**: For children, you need:
- Consent from **both parents**
